# Platform marks

The renderer embeds an allowlisted subset of the pinned `simple-icons` npm package as SVG paths. No user-provided SVG, URL, or remote asset is loaded. Source: https://github.com/simple-icons/simple-icons (CC0-1.0). See the package's icon metadata for each upstream brand source and license information.

Supported canonical IDs: `github`, `typescript`, `javascript`, `python`, `go`, `rust`, `ruby`, `solana`, `ethereum`, `bitcoin`, `react`, `docker`, `kubernetes`, `terraform`, `claude`, `nodejs`, `postgresql`.

Simple Icons' CC0 license does not grant rights to the underlying trademarks. Marks belong to their respective owners. They identify tools/platforms inferred from selected evidence and do not indicate affiliation or endorsement. Use `--no-branding` to omit them. Unsupported IDs are omitted rather than replaced with invented logos.
